PGBloom Authentication

Passwords, JWTs, sessions, and OTP workflows.

What it is

Authentication provides users, password hashing, HS256 access/refresh JWTs, database-backed sessions, logout, password reset, email verification, passwordless OTP login, and cleanup.

Why it exists and when to use it

Use it as an authentication building block. It does not provide Express/Fastify middleware, roles, permissions, or authorization guards; applications must enforce authorization after token verification.

Architecture and internal implementation

Passwords use Argon2id by default; refresh tokens are hashed in pgbloom_sessions. OTPs are hashed, expire after five minutes, allow five attempts, and have a default 60-second resend cooldown. Related: /aiagent/model, /aiagent/deployment, /aiagent/troubleshooting.

Public API and signatures

client.auth(options?) returns Auth with signup, login, logout, refreshToken, verifyToken, me, password-reset methods, OTP methods, and cleanup. Standalone exports include token, password, and OTP helpers.

Parameters and returns

Use the signatures above as the public contract. Optional values use the defaults in Configuration; successful asynchronous operations return the stated promise value, while mutations may return void, a count, an identifier, or a result object.

Errors, concurrency, and failure scenarios

Invalid inputs throw the package validation/configuration error for the relevant subsystem. PostgreSQL failures propagate as database errors. Concurrent behavior is controlled by PostgreSQL transactions, row locks, listener state, TTLs, or atomic updates as described above. Treat expiry, process termination, database outages, duplicate work, and cleanup races as expected failure scenarios.

When not to use it

Do not use this feature outside its runtime boundary, as a security decision, or as a replacement for a stronger external system when its documented durability and delivery model is insufficient.

Example

const auth = client.auth({ jwtSecret: process.env.JWT_SECRET });
const result = await auth.login({ email, password });
const user = await auth.me(result.accessToken);

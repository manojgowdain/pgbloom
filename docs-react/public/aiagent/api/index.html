PGBloom API Inventory

The source of truth for this inventory is src/index.ts, src/server.ts, src/browser.ts, and src/client/PGSnap.ts. Types are emitted from the same TypeScript implementation.

Client factory

createPgbloom(connectionString: string, options?: PgbloomOptions): Promise<PgbloomClient> creates the pool, verifies connectivity, initializes tables, and returns the high-level client. client.close(): Promise<void> stops timers/listeners and closes the pool.

Client methods

Cache: getCache, setCache, deleteCache, clearCache, clearExpiredCache. Pub/Sub: publish, subscribe. Queue: enqueue, dequeue, completeJob, failJob, getQueueStats, cleanupJobs. Lock: tryLock, lock, unlock, acquireLeadership, releaseLeadership, isLeader. Scheduler: schedule, scheduleRecurring, cancelSchedule, getSchedule, listSchedules. Rate limit: rateLimit, rateLimitTokenBucket. Events: emit, listen, getEventHistory, replayEvents. Counters: increment, decrement, add, subtract, getCounter, setCounter, removeCounter. Factories: model, auth, bloom.

Standalone exports

Lock exports include createLockState, tryLock, lock, unlock, acquireLeadership, releaseLeadership, isLeader, renewLeadership, getLockInfo, and extendLock. Scheduler exports include createSchedulerState, schedule, scheduleRecurring, cancelSchedule, getScheduleJob, listScheduledJobs, getAndClaimDueJobs, claimScheduledJob, completeScheduledJob, and failScheduledJob. Rate-limit exports include createRateLimitState, rateLimit, rateLimitTokenBucket, checkRateLimit, checkSlidingRateLimit, checkTokenBucketRateLimit, cleanup, generateKey, generateUserKey, and generateIpKey.

More standalone exports

Events export createEventsState, emit, listen, getEventHistory, replayEvents, and closeEvents. Counters export createCounterState, increment, decrement, add, subtract, get, set, remove, list, and clearAll. Models export createModelState and createModel; auth exports createAuthState, createAuth, password/token/OTP helpers; storage exports createLocalStore, SSDiskStore, and MemoryCache.

Browser and errors

pgbloom/browser exports Bloom/hash, serialize, deserialize, validateKey, and MAX_KEY_LENGTH. Main exports include PGBloomError, database, validation, auth, OTP, config, Bloom, and cache-key errors plus legacy PGSnap* aliases. See feature pages for parameters, return values, failure behavior, and examples.

Example

import { createPgbloom } from "pgbloom";

const client = await createPgbloom(process.env.DATABASE_URL!);
const value = await client.getCache("user:42");
await client.close();

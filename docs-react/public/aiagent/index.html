PGBloom AI Agent Documentation

PGBloom is a PostgreSQL-first infrastructure toolkit for JavaScript and TypeScript. It provides cache, Pub/Sub, queues, distributed locks, leader election, scheduling, rate limiting, events, counters, CRUD models, authentication, OTP, Bloom filters, serialization, and local storage.

Source of truth

Documentation is derived from the TypeScript implementation in src/, public entrypoints, and tests in test/. The React site is only the presentation site; this namespace is static HTML and plain text for crawlers.

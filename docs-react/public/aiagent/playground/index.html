PGBloom Interactive Playground

Controlled browser execution for browser-safe PGBloom APIs with measured traces; server-only APIs use clearly labeled client-side demo simulations.

What it is

The interactive playground executes the browser-safe PGBloom implementation in the browser and displays measured trace steps, Bloom hash positions, output, and errors.

Why it exists and when to use it

Use it to learn Bloom filters, serialization, deserialization, and key validation without credentials. Server-only PostgreSQL APIs are listed but blocked.

Architecture and internal implementation

No arbitrary code, SQL, credentials, filesystem access, or network execution is available. A future sandbox backend would be required for real PostgreSQL traces. Related: /aiagent/browser, /aiagent/bloom-filter, /aiagent/architecture.

Public API and signatures

The playground allowlist includes BloomFilter.add, BloomFilter.has, BloomFilter.clear, serialize, deserialize, and validateKey.

Parameters and returns

Use the signatures above as the public contract. Optional values use the defaults in Configuration; successful asynchronous operations return the stated promise value, while mutations may return void, a count, an identifier, or a result object.

Errors, concurrency, and failure scenarios

Invalid inputs throw the package validation/configuration error for the relevant subsystem. PostgreSQL failures propagate as database errors. Concurrent behavior is controlled by PostgreSQL transactions, row locks, listener state, TTLs, or atomic updates as described above. Treat expiry, process termination, database outages, duplicate work, and cleanup races as expected failure scenarios.

When not to use it

Do not use this feature outside its runtime boundary, as a security decision, or as a replacement for a stronger external system when its documented durability and delivery model is insufficient.

Example

const client = await createPgbloom(process.env.DATABASE_URL!);
try {
  await client.setCache("user:42", { name: "Ada" }, 60_000);
} finally {
  await client.close();
}
